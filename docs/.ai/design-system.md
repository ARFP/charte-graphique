Rôle : Tu es un designer UI / développeur Front-End expert.

Objectif : Générer une page HTML/CSS unique servant de "Style Guide" (ou UI Kit) pour présenter la charte graphique et les composants d'une application web.

Consignes de structure et de style :
1. Utiliser un fichier HTML unique avec du CSS moderne (Variables CSS / Custom Properties dans :root).
2. Code propre, accessible (respect des contrastes WCAG) et structuré.
3. Ne pas utiliser de framework externe (pas de Bootstrap, pas de Tailwind). Tout doit être en CSS pur.

Contenu attendu sur la page :

1. En-tête : Titre du projet "Style Guide - Application Web" et une brève description.
2. Couleurs : Des cartes représentant les couleurs avec leur nom et leur code HEX (Couleur primaire, secondaire, fond, texte, succès, erreur).
3. Typographie : Exemples visuels de la hiérarchie (Titre 1, Titre 2, Titre 3, Texte courant, Texte en gras, Petite mention).
4. Boutons : Une section montrant les boutons (Primaire, Secondaire, Danger) dans leurs différents états (normal, survol, désactivé).
5. Formulaires : Un formulaire modèle contenant :
   - Un champ texte (avec label et placeholder)
   - Un champ type email et number (avec label et placeholder)
   - Un champ avec une erreur (champ rouge + message d'erreur en dessous)
   - Un textarea
   - Un champ avec une erreur (champ rouge + message d'erreur en dessous)
   - Une case à cocher (checkbox) et un bouton radio
   - Un menu déroulant (select)
6. Composants UI :
   - Une carte de contenu (Card) avec une image factice, un titre, un paragraphe et un bouton.
   - Des badges d'état (Succès, En attente, Erreur).

Rends le rendu visuel moderne, espacé, clair et agréable à regarder.
